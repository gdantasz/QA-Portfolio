# Bug Reports

## Objetivo

Esta pasta contém exemplos de relatórios de defeitos encontrados durante a execução dos testes.

## Conteúdo

Cada relatório possui:

- ID do Bug
- Título
- Descrição
- Severidade
- Prioridade
- Passos para reprodução
- Resultado esperado
- Resultado obtido
- Evidências
