# 🧪 QA Portfolio

Bem-vindo ao meu portfólio de **Quality Assurance (QA)**.

Este repositório reúne meus estudos, projetos e documentações desenvolvidos durante minha jornada de aprendizado em Testes de Software. O objetivo é demonstrar minhas habilidades em testes manuais, documentação, testes de API, SQL, automação de testes e boas práticas utilizadas no dia a dia de um Analista de QA.

---

## 🎯 Objetivos

- Demonstrar minha evolução na área de Quality Assurance.
- Aplicar na prática os conceitos estudados.
- Construir um portfólio profissional para processos seletivos.
- Compartilhar conhecimento e boas práticas de testes.
- Documentar minha evolução de forma organizada.
